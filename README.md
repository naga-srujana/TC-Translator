# 🔍 T&C Translator

## Overview

T&C Translator is a web application that helps users understand lengthy Terms & Conditions documents in simple and easy-to-read language. Instead of reading pages of complex legal text, users can paste the Terms & Conditions of any application or website and receive an AI-generated summary of the most important points.

A unique feature of the project is **Savage Mode**, which explains legal clauses in a humorous and engaging way, making the information easier to remember. The application also provides reading statistics, a certificate summarizing the agreement, and a leaderboard that stores analyzed applications using an H2 database.

---

## Features

- 📋 Analyze Terms & Conditions from any website or application
- 🤖 AI-powered legal document analysis
- 📊 Trust Score generation based on fairness and transparency
- 🚨 Identification of critical clauses that may affect user rights
- ⚠️ Detection of warning clauses users should be aware of
- ✅ Highlighting of fair and user-friendly policies
- 🔥 Savage Mode for fun and engaging explanations
- ⏱️ Reading time and document statistics
- 🏆 Certificate of Agreement generation
- 📈 Leaderboard to compare analyzed applications

---

## How It Works

1. The user pastes the Terms & Conditions text into the application.
2. The system calculates document statistics such as word count and estimated reading time.
3. The text is sent to an AI model for analysis.
4. The AI identifies important clauses and generates:
   - Trust Score
   - Summary of the document
   - Critical clauses
   - Warning clauses
   - Fair clauses
5. The results are displayed through an interactive and user-friendly interface.
